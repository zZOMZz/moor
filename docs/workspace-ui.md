# 工作区界面

Web 与桌面共享一套工作区组件和控制器，平台只提供普通 HTTP 或有限原生能力，详见[统一客户端与旧数据](browser-client.md)。

模型、权限与上下文/额度入口的行为及协议见[输入区控件](model-controls.md)。

界面以黑、白和中性灰呈现。设置中的 Dark mode、Light mode、Auto 分别固定深色、固定浅色和跟随系统；默认为 Auto。浏览器保存本机外观偏好，桌面通过可信 IPC 保存到用户数据目录并同步已打开窗口，不写入项目或会话。

## 导航与输入

侧栏的会话区域依次为「置顶、项目、最近」，上下分别保留工作区切换、新对话、新项目和账号/设置。「最近」汇总当前工作区内未置顶、未归档的会话，所有条目保留原账号、设备、项目和执行身份。跨项目列表只读获取，不改变正在编辑的草稿。

本机和普通远程项目默认收起；点击项目名称只展开或收起，多个项目可以同时展开。每个项目先显示最近 5 条会话，通过「展开显示／收起」控制其余条目。项目悬停或键盘聚焦时，右侧依次出现菜单和新建对话按钮。新建对话使用被点击项目的 Agent；菜单提供「查看已归档」和兜底的「重新同步」。

置顶、项目和最近区域复用相同会话行：标题打开会话，悬停或键盘聚焦时显示置顶／取消置顶和归档按钮；右键或触屏长按提供重命名、置顶与归档菜单。运行中的会话不可归档。归档列表可恢复会话，包括已置顶后归档的条目。整理其他会话不会切换当前对话，修改经原执行主机确认后更新列表。侧栏可以调整宽度或折叠，窄窗口改为抽屉。

macOS 关闭、最小化和全屏按钮位于侧栏顶部的原生区域，不再增加独立标题行和大号标志。Windows/Linux 保留原生窗口装饰。

输入框上方显示项目、执行电脑和 Git 工作目录；切换执行上下文不会把已保存的草稿带到另一个身份。附件与 Skills 位于「+」菜单，空输入框按 `$` 可打开 Skills；Cmd/Ctrl+Enter 提交当前指令。审批选项在输入框底栏左侧，模型和推理强度在右侧共用一个面板；该面板可把当前模型和强度设为同一 Agent 配置后续新会话的默认值。发送按钮旁的圆环显示上下文占用，展开可查看账号额度与重置时间。能力来自实际 Agent，工作区就绪后探测一次，后续复用；设置显示最近成功时间、项目作用域和错误，并提供手动刷新。审批默认值保存在执行主机，首次为 Agent。

输入与本机恢复数据分为三层。UI State 保存当前文字和控件交互，每次输入只更新组件内存，不发布全局工作区状态。Draft State 按账号、设备、工作区、项目和会话单独保存未发送文字与运行选项；连续输入合并后保存，切换会话、发送或页面退出前主动落盘。Ledger 只保存必须可靠确认的原操作、附件和功能状态，使用严格事务与版本校验；普通草稿保存不会复制、校验或重写 Ledger。

发送是三层之间的明确边界：先保存最新 Draft State，再把当时的文字、运行选项和附件版本固化为不可变原操作写入 Ledger，最后才请求执行主机。回执确认后按草稿版本清空已发送文字；若发送期间又有新输入，版本不同，新内容不会被清除。恢复草稿或重新联网只读取数据，绝不自动执行。

执行电脑连接状态与会话加载状态分别建模。最近使用的会话视图保留在有界内存快照中，最多 30 个且总计不超过 32 MiB，命中时直接切换；IndexedDB 快照在 120ms 内恢复时也不展示过渡页。只有确实无快照或本机读取较慢时，主区才显示单独的 Moor Logo。打开会话或手动刷新期间在标题栏右上角显示旋转图标；只有主机读取实际失败才标记执行电脑不可达。同步期间只暂停依赖主机最新确认的发送和变更，不锁住侧栏或其他会话导航；快速连续选择由会话 generation 丢弃旧响应。自动增量补读保留当前视图和输入，不取代尚未完成的前台读取。

有历史内容后，右上角显示环境信息面板，集中提供文件、diff、Git/worktree 和 GitHub 入口。新会话隐藏该面板；工作目录仍可从输入框上方选择。会话元数据、Fork 和信息位于省略号菜单。

## 移除功能与已有数据

网页预览、角色预设、旧父子任务和逐回合额外 MCP 的客户端组件、主机新增执行与本机配置入口已经退场。新指令不附带这些旧草稿；旧数据只提供按原范围读取和核查。本机 Agent 配置及明确提交的新共享任务队列继续保留。

已有会话与原请求不删除、不在重连时重放。会话待确认请求保留原编号核查；旧父子任务请求只在存在遗留记录时提供核查；不重试新增执行、不创建计划或授权，也不伪造封存结果。差异与错误可使用语义颜色，主题表面与主操作保持黑白。

这些已移除功能的客户端控制器及其专属交互测试也已清理。旧数据格式、图片与请求摘要校验、原账号和执行目标绑定继续由工作区存储和原操作账本维护；任务与 MCP 的原指令摘要共用同一实现。兼容回归见[旧工作区记录](../tests/integration/workspace-feature-compatibility.test.ts)、[旧预览与标注](../tests/integration/project-preview-compatibility.test.ts)和[原加密请求账本](../tests/integration/retired-browser-records.test.ts)。普通本机设置、有限历史读取协议和合成主机边界测试继续保留。

## 验证范围

自动测试使用合成账号、会话、主机和确定性信号。`pnpm exec electron scripts/validation/check-workspace-layout.cjs` 检查实际 Chromium 中的深色/浅色/Auto、重载持久化、环境面板显隐、侧栏宽度持久化与 390px 抽屉布局，并将截图写入临时目录。原生标题栏配置另有平台测试。

这些检查不等同于已签名安装包、真实 Agent 账号或真实多设备端到端验收。
