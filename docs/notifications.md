# 任务通知

通知用于提醒查看回合完成、失败或待处理的权限请求。桌面通知和 Web Push 分别开启；默认关闭。通知不包含会话标题、正文、文件路径、工具参数或审批按钮，点击后只打开会话并重新读取主机状态。

## 开启与关闭

Mac 本机通知在 **Moor → 连接设置 → 本机任务通知** 中开启，并可选择提醒类型、测试系统通知或关闭。打开设置不会自动请求系统通知权限。只关闭窗口时，Moor 仍可接收自己执行主机的事件；明确退出应用后，执行组件停止，不再接收通知。系统权限、专注设置、签名和电脑休眠仍可能影响显示。

远端 Web/PWA 从账号菜单打开**通知设置**。中转服务先按[部署说明](../deploy/README.md#配置-web-push)配置 Web Push；页面将显示未配置或浏览器不支持的具体原因。用户点击“在此浏览器开启通知”时才请求权限和创建订阅，刷新、重连和登录不会自动订阅。提醒类型可单独保存。

“关闭此浏览器通知”会清除本机通知绑定，删除对应服务器记录，并注销浏览器订阅。服务器未确认时保留“停用待确认”，可手动重试关闭。设置页区分本机订阅和当前登录下的服务器记录，不把仅存于服务器的旧记录显示成本机已开启。退出登录会在服务器事务中停用该次登录的订阅，同时清理浏览器绑定和已有提醒；其他登录端保持各自设置。

iPhone/iPad 的 Web Push 要求把网页应用添加到主屏幕，并从主屏幕打开后通过用户点击请求权限；这项平台能力从 iOS/iPadOS 16.4 开始提供。真实后台送达还需在目标设备验证。[WebKit 平台说明](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/)

## 送达和过期

执行主机只为已持久保存的状态生成通知，事件绑定执行用户、电脑、工作区、项目、会话和回合；权限请求还绑定原请求编号。同一回合只有一个终态通知，权限请求按请求去重。取消回合不产生完成通知。中断后恢复为失败的回合可以生成失败提醒，恢复不会继续运行 Agent。

完成/失败提醒有效期为 24 小时，权限提醒为 30 分钟。权限请求被回答、取消或回合结束后，主机不再提交该请求的新通知。已经到达系统通知中心的旧提醒可能仍可见；点击后读取当前会话，不能批准失效请求，也不会发送或停止回合。

主机分别保存桌面与远端渠道的确认。连接确认超时可重发原通知事件；执行指令仍遵循原来的手动重试规则。桌面只在系统通知组件报告显示后确认，系统拒绝或不支持不会反复请求权限。中转在发送前保存事件标识和投递状态；推送服务接受、失败或结果不确定后，都不会自动再次发送同一事件。推送服务接受请求不代表用户已收到或读过提醒。

主机保留最多 1,000 条活跃通知，过期与溢出记录不会在重连后复活。中转限制每账号最多 1,000 条未过期事件和 20 条订阅记录，全服务最多同时发出 4 个推送请求。设备撤销、登录过期、项目归属变化和执行连接替换会在排队发送前重新校验；新的连接不能继续使用旧连接的发送授权。

Web Push 到达时，如果登录不可确认、账号已切换、提醒过期或本机绑定已关闭，后台组件只显示没有旧会话标识的通用提醒，点击打开 Moor 首页。已发出的推送无法撤回；WebKit 要求每次处理 push 都显示可见通知，因此关闭后仍可能出现先前已排队的一条通用提醒。[WebKit 对可见通知的要求](https://webkit.org/blog/16535/meet-declarative-web-push/)

## 数据与支持范围

中转保存私有推送订阅地址、加密公钥及鉴权材料，以及去重所需的标识、事件类型、时间与状态；不保存通知中的会话正文，也不向推送服务提供正文。订阅绑定账号和具体登录凭据的哈希，接口不返回订阅密钥。VAPID 私钥只由中转操作者配置，不进入共享工作区、前端包或程序归档。

首版只接受以下确切的 HTTPS 推送服务主机：`fcm.googleapis.com`、`updates.push.services.mozilla.com`、`web.push.apple.com`。任意 URL、IP、其他端口、重定向及其他主机均拒绝。Apple 官方允许的地址范围更广；若浏览器分配其他 `push.apple.com` 子域，当前 Moor 会明确拒绝，需要验证后再增加支持，不能据此声称所有 Safari 环境可用。[Apple 推送服务说明](https://developer.apple.com/documentation/usernotifications/sending-web-push-notifications-in-web-apps-and-browsers)

实现使用锁定的 `web-push` 3.6.7 生成标准加密请求，自有 HTTPS 传输限制请求大小、响应和总超时。传输与系统通知测试使用合成订阅、注入计时器和模拟系统事件；没有发送真实推送、使用真实 Agent 账号或验证 macOS 通知中心。PWA 后台、系统权限、休眠/退出和通知点击需按[设备验收](validation.md)完成专项检查。
