# 项目网页预览

Moor 可以连接执行电脑上明确登记的开发服务，由独立 Electron 进程渲染页面，再向客户端返回 PNG 画面。会话面板支持调整视口、定位元素、点击、输入、按键、滚动和同服务内导航，也可以保存元素标注并明确加入原会话草稿。

预览不会启动开发服务器、扫描端口或调用 Agent。只有用户手动连接后才打开页面；页面自身的脚本和请求会运行，交互可能修改应用数据。服务登记表示本机操作者确认该服务属于所选目录，网络连通不能证明开发服务器的实际工作目录。

## 在执行电脑登记

1. 先在 Moor 保存本地项目，并自行启动开发服务器。
2. 打开 **Moor → 连接设置 → 项目网页预览**，刷新本机登记。
3. 选择主机列出的执行目录：项目原目录，或已就绪的会话 worktree。设置窗口会显示实际目录，不能从远程填写任意目录。
4. 填写名称、`127.0.0.1` 或 `::1`、端口及起始路径。需要开放预览时勾选“允许自己的设备查看和操作此服务的页面”，再保存。
5. 停用或删除登记会使已有预览失效，但不会停止开发服务器。更换服务目录前先删除旧登记，再明确登记新目标。

配置固定主机身份、项目与执行目录身份。新 worktree 不会继承原目录的端口；同目录 Fork 可以使用同一执行目录的登记。目录被替换、worktree 被移除或会话执行绑定改变后，原预览不能继续使用。相同服务地址不能同时登记给不同执行目录，Moor 自身的服务端口也不能登记为预览。

支持 HTTP 回环地址和 `1–65535` 端口，包括规范化后的默认端口 `80`；不接受 `localhost`、局域网地址、任意 URL 或 HTTPS。起始路径必须属于当前服务，例如 `/`、`/app?mode=review`、`/#/settings`，不接受路径跳转、其他 origin 或控制字符。

## 本机 CLI

CLI 与桌面使用同一配置。先退出持有该主机数据库的 Moor 实例；关闭窗口不等于退出。将下列占位路径替换为原主机的数据路径：

```sh
node dist/bridge.mjs \
  --config /absolute/private-moor/bridge-v3.json \
  --runtime-data /absolute/private-moor/runtime-v1.sqlite \
  --preview-config-stdin <<'JSON'
{"action":"read"}
JSON
```

读取返回 `revision`、可用 `targets` 与已登记 `services`。从目标列表选取 `localProjectId` 和 `executionId`，不要推测编号或传入 `rootPath`。保存动作示例：

```json
{
  "action": "service-save",
  "expectedRevision": 0,
  "localProjectId": "replace-with-project-id",
  "executionId": "shared",
  "label": "项目前端",
  "address": "127.0.0.1",
  "port": 5173,
  "startPath": "/",
  "enabled": true
}
```

通过同一个 stdin 命令提交上述 JSON，将 `expectedRevision` 替换为刚读取的值。`shared` 表示原目录；worktree 使用目标列表返回的实际执行编号。

| 动作              | 字段与行为                                                                                                                           |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `read`            | 读取本机配置；不探测或连接服务                                                                                                       |
| `service-save`    | `expectedRevision`、目标编号、`label`、`address`、`port`、`startPath`；修改已有服务时加 `id`。`enabled` 省略时为关闭，包括修改登记时 |
| `service-enabled` | `expectedRevision`、`id`、`enabled`；启用或停用原登记                                                                                |
| `service-remove`  | `expectedRevision`、`id`；删除原登记                                                                                                 |

版本冲突或响应丢失后，先手动读取再决定修改，不自动重试。每次配置变更都会产生新版本，停用后再启用也不会恢复旧预览授权。stdin 一次接收一个 JSON，最多 16 KiB。退出码 `0` 表示成功，`1` 表示输入或配置失败，`3` 表示运行锁不可用。该命令不能与 `--desktop`、`--pair` 或 `--github-config-stdin` 同用。

配置固定保存在主机数据库旁的 `preview-v1.json`，没有独立配置目录参数；数据库所在私有目录须在所有登记项目与 worktree 之外。

## 连接、操作与关闭

会话面板先手动读取服务列表，再选择服务与视口并连接。客户端看到的是执行电脑生成的截图，不是能直接访问回环地址的 iframe，也不会把主机 Cookie 或开发服务端口直接交给远程浏览器。

在画面上选择位置只定位元素，不点击页面。确认元素后可分别点击或输入；密码框不接受文字输入。视口、滚动、按键、重载和导航都是明确操作。页面或画面版本变化后，需要重新获取画面和定位，旧元素编号不能复用于新画面。

操作先在本地保存固定编号和目标，主机记录去重状态后才派发。刷新、重连和“核查原预览操作”不会重新执行原点击、输入或连接。结果未知时保留原请求，可手动核查或关闭原连接；关闭后可以另行连接，但不能把关闭解释为撤销已经发生的页面操作。即使连接请求尚未到达主机，关闭也会终止其原编号，迟到请求不能再打开页面。

## 保存标注与发送

定位元素后填写说明，选择是否保留 PNG，再点击保存冻结标注。记录包含服务、路径、时间、视口、元素文本与边框、说明，以及可选截图；后续页面变化不会重算这份记录。

保存只写当前设备的本地草稿。用户还需点击“加入原会话草稿”，发送时文字标注才随普通指令交给 Agent；截图需要另行选择“将截图作为附件”，并满足 Agent 图片能力和附件数量限制。仅定位、保存或勾选标注不会上传截图、发送指令或启动 Agent。

只有收到原指令的有效主机确认后，才清除该次发送对应的标注选择。新选择、编辑后的版本和其他会话的标注不会被旧确认清除。已发送的文本和截图适用普通会话历史规则，之后关闭预览或撤销服务登记不会删除这段历史。

## 保存范围与限制

- 主机私有 JSON 保存服务登记及目录身份，文件权限为 `0600`；不需要 GitHub token 或 Agent 凭据。自动文件树、回合快照和手动文件读取保留 `preview-v1.json` 及其 `.tmp-*` 文件名，大小写不敏感。
- 主机 SQLite 只保存预览操作摘要与最小回执，不保存画面、页面正文或输入文字。实时渲染上下文是临时的，不复用 Moor 登录、页面 Cookie 或设置窗口；关闭后回收。
- 中转转发预览请求和画面，不持久保存这些内容。当前 HTTPS/WSS 没有额外端到端加密，中转进程能看到转发中的画面与交互数据。
- 浏览器保存原待确认请求和最小回执，因此明确输入的文字可能存在本地 outbox 中；实时画面只在内存。主动保存的标注与截图另进入本地标注草稿，最多 20 条，截图合计最多 64 MiB。
- 每个预览实例只允许一个登记 origin。外部 CDN、字体、分析服务、其他端口的 API，以及跨 origin 导航会被阻止；相关页面可能无法完整显示。同 origin WebSocket 用于开发服务更新，握手和目标受限，不提供通用 socket 或任意 CONNECT 通道。
- 不提供文件选择、下载、弹出窗口、摄像头、麦克风或系统权限。原生 Agent 仍不是文件系统沙箱，主机私有数据必须保存在代码目录外。
- 元素定位覆盖主页面及开放的 Shadow DOM，不进入 iframe 或封闭的 Shadow DOM。持续改变 DOM 的页面需要重新截图后定位；视频与动画本身不会成为可重放的历史内容。
- 同时最多 4 个实例；视口为 `240–1920 × 240–1200`，每幅 PNG 最多 4 MiB。一次操作最多 20 秒。页面资源、并发请求和 WebSocket 流量也有限额，超限会中断对应请求或连接。
- 空闲租约为 30 秒；面板保持可用时会发送状态请求续期。关闭面板、切换目标、离线或主机退出会清除画面并尝试关闭原连接。后台浏览器可能暂停计时与网络，租约到期后需要手动重新连接；长连接不能替代租约，也不保证后台持续运行。

主机需要可启动的锁定 Electron `44.3.0` 及图形环境。macOS 应用包包含 worker 并使用自身 Electron；仅部署 relay 不会获得渲染能力。缺少运行环境时明确显示不可用，不自动下载浏览器。

本批自动化使用合成项目和页面；响应式视口不等于真实手机浏览器。真实设备、真实项目服务和最终发行包体验尚未验收，最新状态见[设备验收](validation.md)。主机私有数据与草稿不进入源码仓库、relay 归档或 Docker 构建上下文。
