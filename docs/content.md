# 文件与内容协议

M2.1 提供按会话范围读取项目文件的主机接口，以及独立的内容类型与缓存客户端。当前没有文件树或预览页面；图片上传、附件发送和历史 diff 采集仍在 M2.2/M2.3。引用类型的存在不表示主机已经保存了附件或文件基线，也不授予文件访问权限。

## 版本与兼容

内容消息使用 `contentVersion: 1`。主机通过 `file-content-v1` 能力开放文件读取，桥接协议继续为 v3，会话格式继续为 v1。这个接口不修改会话文档或主机数据库，因此无需迁移已有会话；旧主机缺少能力时，中转拒绝读取并提示更新执行电脑。

每份内容的版本为实际字节的 `sha256:` 摘要，与文件修改时间无关。描述信息包括字节数和媒体类型。当前文件读取上限为 **1 MiB**，返回规范 base64；有效 UTF-8 且不含 NUL 的内容标为 `text/plain`，其他内容保留为 `application/octet-stream`，不会用替换字符伪装成文本。

附件引用预留 `attachmentId`、显示名称、内容摘要、字节数与媒体类型，单份上限为 8 MiB。显示名称不能用于生成磁盘路径。diff 引用预留回合标识和至多 500 个文件的前后内容描述；新增、删除和重命名分别保留对应的空基线或原路径，同一前基线来源或后基线目标不能重复。实际上传、持久化、输入兼容性与历史基线采集必须在后续实现时校验这些约束。

## 主机读取

接口为 `POST /api/workspaces/:workspaceId/replicas/:replicaId/file-content`，只接受 JSON 请求，整个请求最多 16 KiB。路径参数中的工作区属于产品组织层，正文中的工作区属于执行主机，不能混用。

```json
{
  "contentVersion": 1,
  "workspaceId": "runtime-a",
  "localProjectId": "project-a",
  "sessionId": "session-a",
  "path": "src/example.ts"
}
```

账号来自登录凭据，设备来自已验证的项目副本映射，客户端不能在正文中替换它们。中转校验产品工作区、副本、执行主机和本地项目的当前归属；主机在访问文件前校验执行工作区、本地项目和会话所有者。读取结束后再次校验权限和归属，期间退出登录、移动或撤销主机的请求不能继续返回文件内容。文件请求必须关联已有会话，不接受任意本机目录或主机路径。

`path` 是未经 URL 解码的项目内相对路径。绝对路径、盘符、反斜杠、空路径段、`.`、`..` 和控制字符均被拒绝；百分号是文件名的字面字符。项目根来自主机本地登记记录，所有符号链接组件均被拒绝，包括指向项目内部的链接。只读普通文件，不读取目录、FIFO、socket 或设备文件。

主机以不跟随符号链接且不阻塞 FIFO 的标志打开文件，核对路径与文件描述符的身份，在读取前后检查目录、文件大小和修改状态。每次最多读取上限加一字节；读取时变大、路径替换或内容变化会返回错误。普通 Node 文件接口无法提供等同操作系统 `openat2` 的原子目录约束；这些检查能拒绝可观察到的替换，但不构成针对恶意本机进程精确反复换回目录的系统沙箱。

主机返回 `confirmed: true`、完整请求范围、路径与内容描述。`status: "content"` 带 base64 字节；若请求附带 `knownVersion` 且本次实际读取的摘要相同，则返回不带正文的 `status: "not-modified"`。后者也必须重新读取当前文件和验证范围，不能凭旧缓存确认。文件不存在、超限和读取期间变化分别返回 404、413 和 409；不能读取的路径或文件类型返回 403。错误不回传本机绝对路径。

文件读取没有执行副作用，不创建 operation 记录、不写入会话、不调用 Agent，也不进入待执行队列。中转仅转发内存中的响应，返回 `Cache-Control: no-store`，数据库不保存路径、摘要或文件字节。

## 访问端缓存

缓存客户端验证响应版本、范围、路径、字节数和实际 SHA-256；内容校验失败时不保存。缓存键包含协议版本、账号、设备、执行工作区、本地项目、会话、相对路径与内容摘要。产品工作区的重新归组不改变已缓存内容的执行身份，但下一次在线读取仍须通过当前路由验证。

缓存保存不可变的具体版本，不维护会被晚到响应覆盖的“最新文件”指针。调用方保留正在显示的摘要；只有本地存在并通过校验的对应字节，才发送条件读取。若缓存丢失、损坏或不属于当前范围，在线请求改为读取完整内容。

离线读取必须指定具体版本，结果标记 `source: "cache"`、`stale: true`；缺少对应缓存时明确不可用。在线读取被拒绝或文件已删除时直接报告错误，不自动用旧缓存冒充当前文件。主机读取成功但本机缓存保存失败时，内容仍可读取，同时返回 `cacheSaved: false`。客户端不监听重连、不自动重试，也不处理附件草稿或发送操作。
