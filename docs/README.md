# 理解 Moor

Moor 把访问界面、执行主机和中转服务分开：你可以换一台设备继续工作，代码与 Agent 仍留在原来的电脑上。这组文档解释它们怎样协作，以及断线、重试、审批时各自负责什么。

初次使用和安装请从[项目首页](../README.md)开始。想理解实现，可以按下面的顺序阅读。

遇到具体问题，也可以直接跳转：

- 两台电脑上的同名项目没有合并：看[项目与副本](concepts.md#项目与副本)。
- 发送后一直显示“结果待确认”：看[重试同一个请求](sync.md#重试同一个请求)。
- 旧页面上的审批不能提交：看[审批只对当前请求有效](session.md#审批只对当前请求有效)。
- 当前文件已经变化，旧 diff 仍显示原内容：看[回合与会话变更](file-changes.md#回合与会话变更)。
- 离线搜索没有结果：看[离线覆盖范围](search.md#离线覆盖范围)。
- 执行组件恢复了，任务却没有继续：看[恢复进程与继续任务](runtime.md#恢复进程与继续任务)。
- 迁移服务器后找不到历史：看[数据放在哪里](core.md#数据放在哪里)，中转备份中没有会话正文。

架构与使用文档描述当前 0.2 开发预览版：Moor 桥接协议 v3、会话格式 v1；功能完善计划分别列出实现进展和待完成验收。示例中的名称和编号均为虚构；简化结构和伪代码用于解释行为，不是可直接调用的完整 API。
