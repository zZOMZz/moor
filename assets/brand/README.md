# Moor icon

Created with the built-in ImageGen tool; no CLI/API fallback was used.

- `moor-master.png`: selected full-resolution raster source.
- `moor.icns`: macOS bundle icon.
- `../../src/web/public/icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `favicon.ico`: shipped Web/PWA icons.
- Sizes and icon containers were produced with macOS `sips`, `iconutil`, and PNG-in-ICO packaging; the artwork itself came from ImageGen.

## Initial prompt

Use case: logo-brand. Asset: a production app icon for Moor, a local-first coding workspace that lets one person connect a phone and multiple computers. One distinctive minimal app icon expressing a quiet local anchor and connected devices. No text or letters. A sculptural ivory mooring loop with three integrated rounded connection points forming one recognizable symbol. Precise contemporary product icon, subtle ceramic depth, soft light, bold silhouette readable at 24 pixels. Square canvas, deep petrol teal (#133F43) and warm ivory (#F4EFE4), centered with generous breathing space. No device mockup, watermark, bright glow, tiny circuitry or existing company logo.

## Final refinement prompt

Use case: precise-object-edit. Final app icon for Moor. Preserve the ivory three-loop mooring symbol exactly in its shape and ceramic style. Change only the backdrop and layout: fill the entire square canvas with a SOLID OPAQUE deep petrol teal color #133F43 (no transparency, no black backdrop), center the symbol vertically and horizontally, and make the entire symbol including shadow fit within the central 64 percent width and height. The background extends all the way to every edge with no rounded corners. One square icon, no text, no extra decoration.
