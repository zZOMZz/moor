从这台电脑开始。

添加项目后即可本地使用。连接个人服务后，你的手机和另一台 Mac 也能访问这里。

连接状态
重新连接不会重启仍在运行的 Agent，也不会重放之前的指令。
本机任务通知

通知默认关闭。启用后，关闭窗口仍可接收本机任务通知；退出 Moor 后停止。

提醒内容

通知仅提醒查看状态，不提供批准操作。系统权限、专注设置与应用签名会影响显示。
GitHub 账号与项目

仅配置这台执行电脑的 GitHub.com 访问。已保存的 token 不会回传到设置窗口，也不会发给中转服务。

展开后读取本机配置。

GitHub 个人访问 token

优先使用仅授权所需仓库的细粒度 token。账号连接检查不代表有目标仓库的读写权限。替换 token 后需重新验证关联项目。
登记项目对应的 GitHub 仓库

请先在下方添加并保存本机项目。只有验证过的项目登记才能从会话访问 GitHub；登记会固定仓库身份，仓库重建后需手动重新登记。
