从这台电脑开始。

添加项目后即可本地使用。连接个人服务后，你的手机和另一台 Mac 也能访问这里。

连接状态
重新连接不会重启仍在运行的 Agent，也不会重放之前的指令。
本机任务通知

通知默认关闭。启用后，关闭窗口仍可接收本机任务通知；退出 Moor 后停止。

提醒内容

通知仅提醒查看状态，不提供批准操作。系统权限、专注设置与应用签名会影响显示。
GitHub 账号与项目

仅配置这台执行电脑的 GitHub.com 访问。已保存的 token 不会回传到设置窗口，也不会发给中转服务。

展开后读取本机配置。

GitHub 个人访问 token

优先使用仅授权所需仓库的细粒度 token。账号连接检查不代表有目标仓库的读写权限。替换 token 后需重新验证关联项目。
登记项目对应的 GitHub 仓库

请先在下方添加并保存本机项目。只有验证过的项目登记才能从会话访问 GitHub；登记会固定仓库身份，仓库重建后需手动重新登记。
项目网页预览

先自行启动开发服务器，再选择它对应的执行目录并登记回环地址。Moor 不启动服务，也不扫描端口。

展开后读取本机登记。

登记本机预览服务

保存表示你已确认此服务属于所选目录；端口连通不代表目录已验证。新 worktree 需要单独登记，不能沿用原目录服务。停用或删除会关闭相关预览，不停止开发服务器。
全局 Skills 目录

在这台执行电脑上登记自己的 Skills 根目录，最多 20 个。保存登记不会扫描目录、读取 Skill 内容或启动 Agent。

展开后读取本机登记。

登记 Skills 根目录

目录路径仅保存在本机配置中。请选择实际目录，不能包含或位于 Moor 私有数据目录。目录被替换后需重新登记；停用或删除只撤销访问，不删除 Skill 文件。
本机 Agent 配置

登记支持 ACP 的本机程序。程序路径与参数只保存在这台执行电脑，自己的其他设备可以选择已启用的 Agent。

展开后读取本机配置，不会启动 Agent。

Agent 与启动配置
每个数组元素是一个独立参数；不会经过 shell 展开。请不要在角色说明或消息中填写凭据。

检查连接会启动一次已保存的 Agent，读取能力后关闭，不发送指令。保存修改会生成新版本；停用或移除只影响新会话，已有会话继续使用原版本。
本机 MCP 服务

为指定项目登记额外 MCP。连接地址、程序参数和凭据只保存在这台执行电脑；每次发送指令仍需在会话中选择授权的服务版本。

展开后读取本机配置，不会启动或连接 MCP。
